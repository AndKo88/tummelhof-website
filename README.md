# Tummelhof Website

Öffentliche Website der Tummelhof-Zeichentrickwelt für Kinder von vier bis sieben Jahren und ihre Familien.

Die statische Website liegt im Repository-Stamm und wird über GitHub Pages veröffentlicht. Die Hauptdomain ist `tummelhof.de`; `tummelhof.com` soll auf die deutsche Hauptdomain weiterleiten.

## Inhalte

- Startseite und Tummelhof-Welt
- alle 14 Figuren des Referenzstands v1
- aktueller 20-Sekunden-Teaser mit Untertiteln
- Impressum und Datenschutzerklärung
- responsive Darstellung für Smartphone, Tablet und Desktop

## Pflege

Die Seite verwendet keine externen Schriftarten, keine Analysewerkzeuge und keine Werbe-Cookies. Neue YouTube-Einbettungen, Formulare oder Tracking-Funktionen erfordern vor Veröffentlichung eine Aktualisierung der Datenschutzerklärung.
